# Jogo da Velha

Jogo da Velhas simples, como atividade da disciplina de programação web da Faculdade de Tecnologia da Unicamp
O jogo é desenvolvido com foco em **interatividade, simplicidade e código modular**, proporcionando uma experiência leve e intuitiva, com um toque da minha personalidade (deixar tudo fofo)

## Demo Online

## Funcionalidades

- Jogabilidade para dois jogadores
- Registro visual de jogadas
- Verificação automática de vitória, empate ou jogada inválida
- Interface limpa e responsiva

## Tecnologias e Skills Aplicadas

- **Linguagens:** JavaScript, HTML5, CSS3
- **Front-end:** DOM manipulação para atualizações em tempo real
- **Boas práticas:** Código modular e organizado, separação de responsabilidades
